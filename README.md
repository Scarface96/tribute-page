# Tribute Page

A tribute page honoring a notable figure with biographical information and achievements.

## 📋 Overview

A responsive tribute page built with HTML and CSS dedicated to celebrating and sharing information about an important person.

## 📖 Features

- **Responsive Design** – Mobile and desktop optimized
- **Biography Section** – Life story and background
- **Timeline** – Key events and achievements
- **Photo Gallery** – Images and memories
- **Quotes** – Inspirational or memorable quotes
- **Legacy Section** – Impact and contributions
- **Timeline Events** – Chronological milestones
- **Links** – References and further reading

## 🛠️ Technologies Used

- **HTML5** – Semantic markup
- **CSS3** – Styling and layout
- **Responsive Design** – Mobile-first approach
- **No Dependencies** – Pure vanilla code

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Scarface96/tribute-page.git
cd tribute-page

# Open in browser
open index.html  # macOS
# or
start index.html  # Windows
```

Or run a local server:
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

Then visit `http://localhost:8000`

## 📄 Page Sections

1. **Header** – Title and subtitle
2. **Main Image** – Portrait or iconic photo
3. **Introduction** – Brief overview
4. **Biography** – Detailed life story
5. **Timeline** – Important dates and events
6. **Achievements** – Major accomplishments
7. **Quotes** – Memorable sayings
8. **Gallery** – Additional photos
9. **Legacy** – Lasting impact
10. **References** – Links and sources

## 🎨 Customization

Edit `index.html` and `style.css` to:
- Change person information
- Update images
- Modify colors and styling
- Add or remove sections
- Customize layout

## 📸 Adding Content

1. Replace placeholder images with actual photos
2. Update biographical information
3. Add relevant dates and events
4. Include inspirational quotes
5. Add links to references

## 💡 Tips

- Use high-quality images
- Keep text concise and engaging
- Maintain consistent styling
- Ensure proper attribution
- Test on mobile devices
